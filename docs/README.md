# 文档索引

| 目录或文件 | 内容 |
| --- | --- |
| `requirements/` | 软件需求规格、用户故事和系统级顺序图 |
| `design/overview/` | 概要设计、组件图和组件级顺序图 |
| `design/detailed/` | 详细设计、类图和对象级顺序图 |
| `deployment/` | Docker、公网和 Railway 部署说明 |
| `management/` | 团队计划、每日记录和完成清单 |
| `submission/` | 课程最终提交六目录映射与缺失材料提醒 |
| `use-case-list.md` | UC01-UC09 用例清单 |
| `追溯表.pdf` | 组员完成的需求、设计、代码和测试追溯表 |
| `project-reference.md` | 数据库字段、状态流转和组内实现参考 |

自动化测试说明和最新本地报告位于 `tests/`；CI/CD 原始证据由 GitHub Actions Artifact 保存。
