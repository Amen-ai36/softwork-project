# 课程最终提交目录映射

依据《软件工程基础实践》任务书第 5-6 页，本仓库根目录已经直接使用以下六个目录。运行 `python 03_devops/scripts/package_submission.py --name <班级-组号-项目名-软件工程基础实践>` 会在 `dist/` 生成相同结构和同名 ZIP。

| 提交目录 | 内容 | 仓库来源 |
| --- | --- | --- |
| `01_source` | 代码或仓库清单 | Django 源码、依赖、模板和静态资源 |
| `02_docs` | 需求、设计、测试、追溯和模型源文件 | 需求、设计、用例、追溯表和开发说明 |
| `03_devops` | Docker、流水线、Kubernetes/Helm、数据库与部署脚本 | Docker、Kubernetes、数据库、部署与打包脚本 |
| `04_tests` | 自动化测试、压力脚本、原始报告与实验数据 | 三层自动化测试和最新报告；流水线日志由 Artifact 保存 |
| `05_management` | 站会简报、看板截图、贡献与权重材料 | 每日记录、任务清单及团队后续补充材料 |
| `06_defense` | PPT、技术总结报告和备用演示材料 | 团队答辩材料，定稿后直接放入该目录 |

打包脚本只收集仓库中已经存在的材料，不伪造尚未完成的压力测试、看板截图、贡献权重或答辩材料。提交前需由团队负责人补齐这些课程材料，并把 GitHub Actions 的测试和 Kubernetes 部署 Artifact 下载到 `04_tests`。
