## 已开始的实现

1. 为三个业务 Deployment 增加 CPU HPA，并纳入 Kustomize。
2. 为 Docker Compose 和 Kubernetes 网关增加 upstream 连接/读写超时、错误拦截和统一 503 备用响应。
3. 增加同一套脚本可分别压测单体和微服务目标，输出吞吐量、平均/P95、错误率以及可选的 Docker CPU/内存采样。
4. 增加故障注入操作手册、HPA 实验脚本和交付物静态校验，避免“有配置但无证据”；已完成一次 Compose 故障记录。
